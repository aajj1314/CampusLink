# CampusLink Router 部署指南 · 小米 AC2100（从原厂到跑通）

> 版本 1.0 · 2026-10-15 · 适用：`campuslink/router/`（Agent 1 交付物）
> 这份指南覆盖 **从一台原厂小米路由器到 CampusLink Router 服务跑起来** 的全过程，
> 比已有的 `router/README.md`（只覆盖"OpenWrt 已就绪之后"）更靠前。

---

## 0. 开始之前：三个必须先确认的事

### 0.1 确认你手里的是哪一台（最重要！）

小米有两台长得完全不同的"AC2100"，**固件不通用，刷错 = 变砖**：

| 型号 | 外观 | OpenWrt 设备名 |
|---|---|---|
| **小米路由器 AC2100（R2100）** | **黑色圆柱形** | `xiaomi_mi-router-ac2100` ← 本项目目标 |
| Redmi 路由器 AC2100（RM2100） | 白色、6 根天线 | `xiaomi_redmi-router-ac2100` |

看路由器底部铭牌确认型号。**本指南的所有命令、镜像下载地址都只对应 R2100（黑色款）。**

### 0.2 风险告知（如实说）

- 刷机会**失去小米官方保修**，操作失败可能变砖（需要 UART/TTL 救砖）。
- 整个过程不需要拆机、不需要焊接，只需网线 + 浏览器 + SSH，风险集中在"刷错机型"和"中途断电"两点。
- **全程用网线把电脑直连路由器 LAN 口**，不要用 WiFi 操作；笔记本保证电量（或插电源）。

### 0.3 回退保底建议（可选但强烈推荐）

社区普遍做法是先刷 **Breed 恢复引导**（hackpascal 开发的通用引导，类似"不死鸟"），
之后无论刷什么失败都能按住复位进 Breed 网页控制台救回来。如果你想走这条路，
在 §1 拿到 SSH 后先 `mtd write breed-mt7621-xiaomi-r2100.bin Bootloader`，
再从 Breed 控制台刷 OpenWrt。**本指南主线走官方 mtd 直刷路径**（命令来自 OpenWrt
官方仓库提交记录，已核实）；Breed 的具体刷法以 [Breed 项目发布页](https://breed.hackpascal.net/) 和社区教程为准。

## 1. 第一步：给原厂路由器刷上 OpenWrt

### 1.1 官方参考（权威来源，遇到与本指南不一致时以它为准）

- 设备页：`https://openwrt.org/toh/xiaomi/mi_router_ac2100`
- 本机镜像（25.12.2 稳定版，从官方 ToH 页核实）：
  - kernel1: `https://downloads.openwrt.org/releases/25.12.2/targets/ramips/mt7621/openwrt-25.12.2-ramips-mt7621-xiaomi_mi-router-ac2100-squashfs-kernel1.bin`
  - rootfs0: `https://downloads.openwrt.org/releases/25.12.2/targets/ramips/mt7621/openwrt-25.12.2-ramips-mt7621-xiaomi_mi-router-ac2100-squashfs-rootfs0.bin`
  - sysupgrade: `https://downloads.openwrt.org/releases/25.12.2/targets/ramips/mt7621/openwrt-25.12.2-ramips-mt7621-xiaomi_mi-router-ac2100-squashfs-sysupgrade.bin`（**首次刷机不用它**，以后升级用）

### 1.2 获取 SSH 权限（网页漏洞法，推荐）

原厂固件锁 SSH，需要先用漏洞打开。步骤：

1. 浏览器登录小米路由器管理页（默认 `http://192.168.31.1`）
2. 看地址栏 URL，取出 `stok=` 后面那串值。例如地址是
   `http://192.168.31.1/cgi-bin/luci/;stok=<一长串>/web/home#router`，就记下 `<一长串>`
3. **依次访问下面三条 URL**（把 `<stok>` 替换成你自己的值，每条都要回车打开）：

```
http://192.168.31.1/cgi-bin/luci/;stok=<stok>/api/misystem/set_config_iotdev?bssid=Xiaomi&user_id=longdike&ssid=-h%3Bnvram%20set%20ssh%5Fen%3D1%3B%20nvram%20commit%3B
http://192.168.31.1/cgi-bin/luci/;stok=<stok>/api/misystem/set_config_iotdev?bssid=Xiaomi&user_id=longdike&ssid=-h%3Bsed%20-i%20%27s/channel=.*/channel=%5C%22debug%5C%22/g%27%20/etc/init.d/dropbear%3B
http://192.168.31.1/cgi-bin/luci/;stok=<stok>/api/misystem/set_config_iotdev?bssid=Xiaomi&user_id=longdike&ssid=-h%3B%2Fetc%2Finit.d%2Fdropbear%20start%3B
```

4. 若漏洞已在新固件被堵（返回错误页），先在管理页"系统升级"里**手动降级**到
   `miwifi_r2100_firmware_4b519_2.0.722.bin`（官方历史固件，官方下载页可取），再重复第 3 步
5. SSH 连接：`ssh root@192.168.31.1`，**密码是路由器底部铭牌上的 SN 序列号**
   （如果改过管理密码，就是你设置的那个）

### 1.3 写入 OpenWrt（在 SSH 里执行）

```sh
# 1) 把两个镜像传上路由器（在电脑上执行；或路由器上直接 wget 上面 §1.1 的 URL）
scp openwrt-25.12.2-ramips-mt7621-xiaomi_mi-router-ac2100-squashfs-kernel1.bin root@192.168.31.1:/tmp/
scp openwrt-25.12.2-ramips-mt7621-xiaomi_mi-router-ac2100-squashfs-rootfs0.bin root@192.168.31.1:/tmp/

# 2) 在路由器 SSH 里执行（顺序不能乱，一条一条来）：
mtd write /tmp/openwrt-25.12.2-ramips-mt7621-xiaomi_mi-router-ac2100-squashfs-kernel1.bin kernel1
nvram set uart_en=1
nvram set bootdelay=5
nvram set flag_try_sys1_failed=1
nvram commit
mtd -r write /tmp/openwrt-25.12.2-ramips-mt7621-xiaomi_mi-router-ac2100-squashfs-rootfs0.bin rootfs0
```

最后一条带 `-r` 会自动重启。**重启期间不要断电**。

### 1.4 首次进入 OpenWrt

- 等待 3~5 分钟，电脑网线连 **LAN 口**（4 个口中靠内侧的 3 个之一）
- OpenWrt 默认地址：`http://192.168.1.1`，默认无密码（第一次进 LuCI 会要求设置 root 密码）
- `ssh root@192.168.1.1` 同样可用

## 2. 第二步：OpenWrt 基础检查

SSH 进路由器，先做三个检查：

```sh
# 1) 确认机型识别正确（应输出 xiaomi,mi-router-ac2100 或等价的 R2100 标识）
cat /tmp/sysinfo/board_name

# 2) 确认 overlay 剩余空间（后面装 Python 要花 ~15 MB，最好 ≥ 30 MB）
df -h /overlay

# 3) 联网（后面 opkg 要用）。按宿舍环境二选一：
#    若上级是校园网（WAN 口插墙上网口，走 DHCP）：
uci set network.wan.proto='dhcp' && uci commit network && /etc/init.d/network restart
#    （若校园网需要 Portal 认证才能出外网，此刻 opkg 会失败 —— 先用手机热点
#      给电脑共享网络，电脑再给路由器 WAN 口供网，或临时把路由器 WAN 插到
#      已认证的网络上；OpenWrt 自身装完 CampusLink 后它自己就会认证了）
```

> **鸡生蛋问题**：opkg 下载需要外网，而外网需要 CampusLink 认证 —— 而 CampusLink 还没装。
> 解法：第一次安装时，让路由器 WAN 口临时接一个能直接上网的网络（手机 USB 共享 /
> 热点网线回插 / 已认证的端口）。装完之后就不需要了。

## 3. 第三步：安装 Python 环境

```sh
opkg update
# 省事路线（推荐，~15 MB，包含全部标准库拆包）：
opkg install python3

# 精简路线（若空间紧张；清单来自 router/README.md，Agent 1 按依赖实测列出）：
# opkg install python3-light python3-logging python3-json python3-urllib python3-lxml
```

说明：
- `python3-lxml` 装不上也没关系——代码里 `_vendor` 机制会让 bs4 自动退回
  `html.parser`（本门户登录页只有 ~5 KB，性能无影响）。
- 跑起来后如果报 `ModuleNotFoundError: No module named 'xxx'`（xxx 是 email /
  codecs 之类标准库模块），那是 OpenWrt 把标准库拆成了小包，`opkg install python3-xxx` 即可。

验证：`python3 --version`（应输出 3.11+）。

## 4. 第四步：打包成 .ipk 并 opkg 安装（通用插件方式）

CampusLink Router 做成了 **OpenWrt 通用插件（.ipk）**，纯 Python、无需交叉编译，
一条 `opkg install` 装好并自动拉 python3 依赖。

在**你的 Windows 电脑**上，`CampusLink/` 目录执行：

```sh
# 产出 dist/campuslink-router_1.0.1_all.ipk（Architecture=all，任何 OpenWrt 目标可装）
python tools/build_ipk.py

# 传到路由器
scp dist/campuslink-router_1.0.1_all.ipk root@192.168.1.1:/tmp/
```

在**路由器**上安装：

```sh
opkg update
opkg install /tmp/campuslink-router_1.0.1_all.ipk
# 自动完成：装 python3 依赖 → 代码放到 /opt/campuslink → 装 init 脚本 → enable 自启
```

> `.ipk` 内含 `Depends: python3`，opkg 会自动装 Python（§3 那步可省，但先装也无害）。
> `_vendor/packages` 里的 requests/urllib3/bs4 已随包带好，路由器上**永远不跑 pip**。

## 5. 第五步：启动服务

```sh
/etc/init.d/campuslink start          # 立即启动（postinst 已 enable 开机自启）
```

看日志确认起来了：

```sh
logread -e campuslink | tail -20
# 期望看到：CampusLink Router 控制面已启动 0.0.0.0:7700
#          认证编排: 未配置（待凭据下发）   ← 正常，见 §8
```

## 6. 第六步：验证

在**路由器上**：

```sh
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:7700/api/v1/health   # 期望 200
curl -s http://127.0.0.1:7700/api/v1/capabilities | head -c 300               # 期望 JSON
```

在**电脑上**（浏览器或 curl，把 192.168.1.1 换成路由器实际地址）：

```
http://192.168.1.1:7700/api/v1/capabilities
```

- 能看到 JSON → 控制面已在局域网可达，**部署成功**。
- 电脑访问不通但路由器本机 curl 通 → 防火墙问题：OpenWrt 默认 LAN 入站是放行的，
  若你改过，检查 `/etc/config/firewall` 里 lan zone 的 `input` 是否为 `ACCEPT`。

## 7. 第七步：Phase 1 验收清单（真机部分）

对照 `docs/design/05-研发路线图.md` Phase 1 的验收标准逐条执行：

| # | 验收项 | 怎么测 | 状态 |
|---|---|---|---|
| 1 | R2100 刷 OpenWrt 25.12.2 成功 | §1 完成且 LuCI 可进 | ☐ |
| 2 | Router 上触发认证返回"认证成功" | §8 下发凭据 → `POST /auth/login` → 看 `/auth/status` | ☐ |
| 3 | 断电重启后自动重连 | 拔电源 → 等 2 分钟 → `curl /health` 通 | ☐ |
| 4 | 48h 常驻内存增长 < 5 MB | 每天记一次：`ps w | grep campuslink` 看 RSS | ☐ |
| 5 | overlay 剩余 ≥ 25 MB | `df -h /overlay` | ☐ |

外加 **R1 关键验证**（决定 Router 模式价值上限）：
Router 认证成功后，用另一台**未认证**的设备（手机连 Router 的 WiFi）访问外网——
能通说明 NAT 后共享认证状态（Router 模式全家受益）；不通说明门户按设备计费/认证，
Router 模式只对 Router 自身有意义。**这条结论直接决定后续投入方向。**

## 8. 凭据下发（方案 A，已实现）

密码走**方案 A**：已配对设备通过 API 下发，Router 只存内存、重启即失，**绝不落盘**。

前提：先用任一已配对设备拿到 `device_token`（§6 里 PC 上跑模拟器配对，或真机配对）。
然后在 PC 上执行：

```sh
# 下发凭据（把 <token> 换成配对得到的 device_token）
curl -X PUT -H "Authorization: Bearer <token>" \
     -H "Content-Type: application/json" \
     -d '{"student_id":"你的学号","account":"你的上网账号","operator":"自动选择","password":"你的密码"}' \
     http://192.168.1.1:7700/api/v1/auth/credentials
# 期望响应：{"configured": true, "student_id": "2024****001", ...}（密码不回显）

# 确认认证就绪
curl -H "Authorization: Bearer <token>" http://192.168.1.1:7700/api/v1/auth/status
#   account.student_id 应是脱敏值，account 下无 password 字段

# 触发一次认证
curl -X POST -H "Authorization: Bearer <token>" \
     http://192.168.1.1:7700/api/v1/auth/login -d '{"wait": false}'
```

**重启后凭据会清空**（设计如此），需重新下发一次。桌面端「自动把本机账号同步到路由器」
的图形入口是后续待办（配合 Phase 2 联调），在此之前用上面的 curl 即可跑通真机认证。

> 安全边界：响应/日志中永不出现密码；凭据只存 Router 内存；`DELETE /api/v1/auth/credentials`
> 可随时清空。

## 9. 常见问题

| 症状 | 处置 |
|---|---|
| `opkg` 报下载失败 | 路由器没外网——见 §2 的"鸡生蛋"说明，先临时给 WAN 接可上网的网络 |
| 启动报 `No module named 'requests'` | vendored 依赖没带上：确认 `campuslink/router/_vendor/packages/` 非空，且 init 脚本里 `CAMPUSLINK_VENDOR=1` 生效（`logread` 里能看到） |
| 启动报 `No module named 'email'/'codecs'/...` | OpenWrt 标准库拆包：`opkg install python3-<缺的模块名>` |
| 服务没起来 | `logread -e campuslink` 看报错；手动前台跑一次定位：`CAMPUSLINK_VENDOR=1 PYTHONPATH=/opt/campuslink python3 -m campuslink.router --port 7700` |
| 电脑访问 7700 不通 | 本机 curl 通就是防火墙问题（§6）；再查 IP 是否变过（`uci get network.lan.ipaddr`） |
| overlay 空间告警 | `df -h /overlay`；精简路线装 Python（§3 注释里的命令）；确认没有日志写进 flash（`ls /opt/campuslink` 下不应有 logs/ 增长，日志在 /tmp） |
| 想看实时日志 | `logread -f | grep campuslink` |
| 想停用 | `/etc/init.d/campuslink stop`；彻底卸载：`/etc/init.d/campuslink disable && rm -rf /opt/campuslink /etc/init.d/campuslink` |
