# CampusLink 用户手册

> 适用版本：CampusLink 1.0.1
> 适用对象：完全没有编程基础的普通用户

CampusLink 是一个让你**连上校园网后自动完成认证**的小工具。
装好之后，开机会自动登录、断线会自动重连，平时根本不用管它。

---

## 一、安装

1. 双击 `CampusLink_Setup_v1.0.exe`
2. 如果 Windows 弹出「已保护你的电脑 / 未知发布者」：
   - 点 **「更多信息」**
   - 再点 **「仍要运行」**
   - 这是因为本程序没有花钱买数字签名，不是病毒
3. 安装向导里：
   - 安装位置：保持默认（`C:\Program Files\CampusLink`）
   - **勾选「开机自动启动」**（推荐）—— 登录 Windows 后自动登录校园网
   - 可选：勾选「创建桌面快捷方式」
4. 点「安装」→「完成」。可以勾选「立即启动」先打开看看

> 个别杀毒软件可能误报。把它加入「信任」或「排除项」即可。

---

## 二、第一次使用：填账号

打开 CampusLink 后，第一次会让你填三项：

| 项 | 说明 |
|---|---|
| 学(工)号 | 你的学号或工号 |
| 上网账号 | 运营商给的账号；和学号相同就留空 |
| 密码 | 上网密码 |
| 运营商 | 一般选「自动选择」 |

填完点 **「立即连接」**。

如果勾选了 **「保存账号信息」**，密码会存进 **Windows 凭据管理器**
（控制面板 → 用户帐户 → 凭据管理器 → Windows 凭据，条目名 `CampusLink:...`），
**不会以明文形式存在任何文件里**。下次启动不用再输。

> 如果你的电脑凭据管理器不可用（极少见），程序会明确告诉你
> 「无法安全保存密码」，这时每次启动都需要重新输一次密码。

## 三、日常使用

### 立即连接
点主窗口的 **「立即连接」** 按钮。状态会显示「正在连接…」，成功后变成绿色「已联网」。

### 检测网络
点 **「检测网络」**：会告诉你现在是「已联网 / 需要认证 / 未连接网络」。

### 自动重连
勾选 **「断线自动重新认证」**：程序会每 60 秒检查一次，掉线时自动重新登录。
这个开关在系统托盘菜单里也有。

### 最小化到托盘
点窗口右上角的 **×**（或最小化按钮），程序不会退出，而是缩到右下角系统托盘。
- 双击托盘图标重新打开窗口
- 托盘菜单：打开主界面 / 立即连接 / 自动重连开关 / 退出

### 开机自动启动
主窗口的 **「开机自动启动」** 复选框，或者安装时勾选过。
登录 Windows 后会自动启动并缩到托盘。

## 四、常见问题

**Q：双击没反应 / 窗口一闪而过？**
A：程序可能在托盘里。看右下角任务栏有没有蓝色 Wi-Fi 图标。
没有的话，按 `Ctrl + Shift + Esc` 打开任务管理器，找 `CampusLink.exe`，
有就在跑、没有就再双击一次。

**Q：状态一直显示「需要认证」，但点连接也没用？**
A：先点 **「检测网络」** 看具体状态。然后：
- 确认连的是**校园网** WiFi（不是手机热点）
- 确认学工号 / 账号 / 密码没填错
- 看「运行状态」里的提示。比如「密码错误」就改密码；「未实名」就要去信息中心办

**Q：提示「验证码错误」一直重试？**
A：偶尔错一两次是正常的，程序会自动换一张重试。如果连续失败，
说明验证码识别模型对这个验证码风格不熟，可以多试几次（重启程序）。
实在不行，用命令行排查：
```
"C:\Program Files\CampusLink\CampusLink.exe"   （不行，GUI 没有 dry-run）
```
更准确的做法：装一份 Python 跑 `campuslink.cli dry-run`，但这需要开发环境。

**Q：换了电脑/重装系统，配置怎么办？**
A：把 `C:\Users\<你的用户名>\AppData\Roaming\CampusLink\config.json` 拷到新电脑的同位置。
**密码不在里面**（在凭据管理器），新电脑上第一次需要重新输密码。

**Q：怎么彻底卸载？**
A：开始菜单 → CampusLink → 卸载。卸载时会问是否删除用户配置。
**注意**：保存在凭据管理器里的密码安装程序删不掉，需要手动去
「控制面板 → 用户帐户 → 凭据管理器 → Windows 凭据」里删掉名为 `CampusLink` 的条目。

**Q：日志在哪？**
A：`C:\Users\<你的用户名>\AppData\Roaming\CampusLink\logs\campuslink.log`
程序内点「查看日志」会直接打开这个文件夹。**日志里不含密码**（已自动脱敏）。

## 五、安全说明

- **密码只存在 Windows 凭据管理器**，配置文件里没有，日志里也不会出现
- 配置文件 `config.json` 在 `%APPDATA%\CampusLink\`，只放账号、运营商、行为开关
- 程序**不会**联网发送你的账号信息到任何第三方服务器，只连校园网认证门户（`10.6.6.6`）
- 这是给你自己用的工具，**不要把含密码的配置文件发给别人**

## 六、键盘操作（无障碍）

- `Tab` 在输入框、按钮间切换
- `空格` 切换复选框
- `回车` 在密码框里时直接点「立即连接」
- `Esc` 取消正在进行的连接

## 七、Router 模式（多设备协同）

### 这是什么

家里/宿舍里多台设备（电脑、手机）都要上网时，可以让一台 **OpenWrt 路由器**
（即「Router」）统一帮你登录认证。路由器是唯一持有登录会话的设备，
你的电脑、手机只是「视觉节点」——帮路由器识别验证码，仅此而已。

### 什么时候用

- 你有一台刷了 OpenWrt 的路由器（例如小米 AC2100），并且装好了 CampusLink Router
- 想让多台设备通过路由器一起上网

> 如果你没有这样的路由器，**不用管这一节**，继续用前面的「立即连接」即可。

### 开启步骤

1. 在主窗口找到 **「Router 视觉节点」** 卡片（在「选项」下面）
2. 勾选 **「作为视觉节点连接 Router」**
3. 在地址框里填路由器的地址，例如 `http://192.168.1.1:7700`
4. 点 **「配对」**：会弹出一个 6 位配对码，在路由器侧确认后点「是」，
   本机会换取一张设备凭据（存在系统凭据管理器里，不写明文）
5. 配对成功后，状态区会显示 **「模式：Router 托管」**

### 托管期间

- 本机的 **「立即连接」按钮会被禁用**（置灰，提示「由 Router 托管」），
  避免和路由器同时登录同一个账号、触发门户的并发限制
- 认证由路由器发起；需要验证码时，本机会在后台自动识别并提交
- 你什么都不用做，保持程序在托盘里运行即可

### 路由器失联怎么办

- 程序会每 2 秒探测一次路由器；连续 3 次（约 6 秒）联系不上就判定失联，
  **自动切回独立模式**并弹通知，本机恢复自己登录的能力
- 路由器恢复后，程序会等待 10 秒稳定，再**自动重新托管**（这是为了防抖，
  避免网络一抖就来回切换）

### 安全与合规

- 本机**不会**拿到路由器的登录 Cookie；你只看到验证码图片、只回填识别文本
- 登录用的仍是**你自己的账号**，仍受门户的并发终端数限制；遇到「并发超限」
  会如实提示，不做任何规避
- 配对码是「分发手段」不是「分享手段」，只用于让你自己的设备接入
