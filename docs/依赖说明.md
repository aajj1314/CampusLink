# CampusLink 依赖说明

完整依赖见 `requirements.txt`。这里按**职责**分组，并说明每项为什么需要、能否替换。

---

## 一、认证核心（`campuslink/core/`）

这一层**必须**跨平台 —— 它将来要能原样搬到 OpenWrt 上。

| 包 | 版本 | 作用 | 能否替换 |
|---|---|---|---|
| `requests` | ≥2.31 | HTTP 会话、提交认证 | 可换 `httpx` / `urllib3`，工作量中等 |
| `beautifulsoup4` + `lxml` | ≥4.12 / ≥5.0 | 解析登录页表单 | `lxml` 可换 `html.parser`（bs4 自带，慢但无依赖） |
| `ddddocr` | ≥1.5.6 | 验证码识别（ONNX 本地推理） | **难替换**：要换识别引擎得重写 `ocr.py` |
| `numpy` | ≥1.26 | 数组运算（被 ddddocr / cv2 依赖） | 跟 ddddocr 走 |
| `opencv-python` | ≥4.9 | 图像预处理（灰度、阈值、形态学） | 可去掉：把 `ocr.STRATEGIES` 砍到只剩 `raw`，就能不依赖 cv2，但识别率会降 |
| `onnxruntime` | ≥1.16 | ddddocr 的推理后端 | 跟 ddddocr 走；OpenWrt 上有 ARM 版本 |
| `pillow` | ≥10 | ddddocr 间接依赖；图标生成用 | 跟 ddddocr 走 |

**关键约束**：`core/` 不 import `PySide6`，也不 import `winreg` / `pywin32`。
这条有测试守着（`tests/test_config_and_secrets.py` 之外的隐式断言见 README 第 2 节）。

## 二、GUI（`campuslink/gui/`）

| 包 | 版本 | 作用 | 备注 |
|---|---|---|---|
| `PySide6` | ≥6.6 | Qt for Python（QtCore/QtGui/QtWidgets/QtNetwork） | 完整安装 650 MB；打包时排除用不到的模块（WebEngine/PDF/3D/Quick 等），实际打包后约 150 MB |

> 打包规格 `packaging/CampusLink.spec` 里 `excludes` 列了 30 多个 Qt 子模块，
> 是体积控制的关键。改之前先看 README 4.10。

## 三、凭据存储（`campuslink/secrets.py`）

| 包 | 版本 | 作用 | 后端 |
|---|---|---|---|
| `keyring` | ≥24 | 跨平台密码存储 | Windows → 凭据管理器；Linux → SecretService；macOS → Keychain |

**没有可用后端时不退化成明文**，而是拒绝保存并提示用户。
`secrets.available()` 在首次调用时检测并缓存，避免每次读写都做后端探测。

## 五、版本固定与升级

`requirements.txt` 用 `>=` 下限而非精确版本，理由：

- 认证逻辑依赖的是**协议**（HTTP / HTML / ONNX 推理 API），不是具体某个版本的内部实现
- 上限固定反而容易在 pip 自动升级某个传递依赖时整套崩掉

**升级风险点**（升级前手动验证）：
- `ddddocr`：1.5 → 1.6 改了模型加载方式（`show_ad` 参数），`ocr.py` 已做兼容
- `onnxruntime`：2.x 改了部分 API，目前锁在 1.x，升级需测 `ocr.warmup()`
- `PySide6`：6.6 → 6.7 改过几个枚举名（`QEvent.Type.WindowStateChange` 等），升级需跑 GUI 冒烟

## 六、体积构成（实测）

| 部分 | 大小 | 说明 |
|---|---|---|
| `dist/CampusLink/` 总计 | 410 MB | onedir 完整产物 |
| `_internal/PySide6/` | ~150 MB | Qt 运行库（已排除 WebEngine 等） |
| `_internal/cv2/` | ~113 MB | OpenCV（含 `cv2.pyd` 82 MB + FFmpeg DLL 29 MB，后者其实没用但 collect_all 会带上） |
| `_internal/ddddocr/` | ~85 MB | 三个 ONNX 模型 + Python 接口 |
| `_internal/onnxruntime/` | ~43 MB | 推理引擎 + 原生 DLL |
| 其余（numpy/PIL/lxml/...） | ~19 MB | |
| `CampusLink.exe` | 9.8 MB | 启动器 |

> 用 Inno Setup 的 LZMA2 压缩后，安装包预计 **~150–180 MB**。
> onefile 模式不推荐（启动要十几秒，每次解压 400 MB 到 temp）。

## 七、OpenWrt 移植要点

core 已经为移植留了条件，移植时只需要：

1. **GUI 整层不要** —— OpenWrt 没有 X11，跑不了 Qt
2. **`ocr.py` 可能要换** —— OpenWrt 上跑 opencv + onnxruntime 内存吃紧，
   可以换成调用路由器本地的识别服务，或者直接去掉验证码环节（如果该门户允许）
3. **`netdetect.py` 的网关读取** —— 已经写了 Linux 分支（读 `/proc/net/route`），
   原样可用
4. **`portal.py` / `authenticator.py`** —— 原样可用，不依赖任何平台 API
5. **`autostart.py` / `secrets.py`** —— 用 init 脚本和文件权限替代

最小移植产物：`campuslink/core/` + 一个 init 脚本，预计 < 5 MB（不含模型）。
