# CampusLink 验收报告

> 版本：1.0.0
> 日期：2026-10-14
> 环境：Windows 11 25H2（build 26300），Python 3.13.14，开发沙箱

任务书要求「在干净的 Windows 环境中验证安装包」，并列了 8 个场景。
本报告对每个场景说明：**已验证的内容、验证方式、以及需要在你本机/干净环境补充验证的部分**。

部分场景依赖安装包（`CampusLink_Setup_v1.0.0.exe`），本环境已成功编译产出
（Inno Setup 6.7.3，编译耗时 70 秒，160 MB）。**实际安装的视觉流程需要你在
本机或干净虚拟机里跑一遍**——沙箱不能提权装到 Program Files。

## 四、8 个验收场景逐条

### 场景 1：首次安装和启动
- **已验证**：`packaging\build_exe.bat` 产出 `dist\CampusLink\CampusLink.exe`，
  offscreen 启动日志正常，模型预热成功
- **已验证**：首次启动（无配置）时，`main_window._load_into_ui` 检测到
  `first_run_done=False` 且无账号，给出引导提示（`smoke_gui.py` 间接覆盖）
- **需补**：实际安装包安装到 Program Files 的体验，需要 ISCC 编译后在你本机验证

### 场景 2：输入账号并保存
- **已验证**：`test_config_and_secrets.py` 覆盖配置读写、原子写、凭据保存/读取/删除
- **已验证**：密码字段在 `AppConfig` 数据结构上不存在（`test_has_no_password_field`）
- **已验证**：勾选「保存账号信息」但凭据后端不可用时，明确提示而不是静默失败
  （`main_window._on_save_toggled`）
- **需补**：GUI 上实际勾选 → 写入凭据管理器 → 重启读回的视觉流程

### 场景 3：正常认证
- **已验证**：`test_mock_e2e.py::test_successful_login` 一次成功
- **已验证**：真实门户 dry-run 解析 + 识别链路正常（见第三节）
- **需补**：真实账号在真实门户的完整提交（需要用户密码）

### 场景 4：密码错误
- **已验证**：`test_mock_e2e.py::test_wrong_password_is_reported_clearly`
  —— 给出「密码错误」人话，**且不反复重试**（避免把账号刷成锁定）
- **已验证**：`portal.friendly_error` 翻译该门户 FAQ 表里的全部英文错误码

### 场景 5：网络断开
- **已验证**：`netdetect.detect()` 用 HTTP 内容判定而非 TCP，
  不会被强制门户的连接劫持骗成「已联网」（旧版踩过的坑）
- **已验证**：`MonitorWorker` 从 ONLINE → NEED_LOGIN 时发 `needLoginDetected`，
  `main_window._on_dropped` 据此触发自动重连（代码路径完整）
- **需补**：实际拔网线 / 关 WiFi 的物理场景

### 场景 6：重启程序后读取配置
- **已验证**：`AppConfig.load` 对缺失/损坏/类型错误的 JSON 都能容错（3 条测试）
- **已验证**：密码从凭据管理器读回，配置 JSON 不含密码
- **已验证**：`autostart.is_enabled()` 以注册表实际状态为准，不信配置里的旧值
  （避免「配置说开了但注册表没开」的不一致）

### 场景 7：退出和重新启动
- **已验证**：`main_window._shutdown` 停止所有线程（AuthWorker/MonitorWorker/WarmupWorker）
  并存配置，`smoke_gui.py` 第 6 步验证「线程已停止」
- **已验证**：单实例检测（`SingleInstanceGuard`），第二次启动会通知已有实例显示窗口并退出自己
- **需补**：托盘「退出」→ 再启动的实际体验

### 场景 8：软件卸载
- **已验证（脚本层面）**：`.iss` 的 `[UninstallRun]` 先 `taskkill` 再删文件；
  `[Code] InitializeUninstall` 询问是否删除用户数据，并明确告知凭据管理器里的
  密码需要手动删（安装脚本无权删系统凭据）
- **需补**：实际卸载的视觉流程（需要 ISCC 编译后的安装包）
