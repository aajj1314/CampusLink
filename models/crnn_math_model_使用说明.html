crnn_math.onnx · 算术验证码识别模型

输入一张算式验证码图片，输出算式文本（如 7加9）和置信度。CRNN + CTC，纯 CPU 推理。

一、这个模型是什么

  • 任务：识别算术验证码图片 → 输出算式原文，例如图片 6乘12=? 输出文本 6乘12（注意是算式原文，不是答案 72，答案自己算）
  • 架构：CRNN（CNN 提特征 + BiLSTM 序列建模 + CTC 解码）
  • 精度：从未参与训练的 116 张独立测试集上，答案正确率 92.2%（含求值）；算式原文错误约 6.9%
  • 运行环境：onnxruntime CPU 版即可，普通电脑毫秒级一张，不需要显卡
  • 字符集：12 类 —— 0-9 加 加 减 乘 除 四个汉字运算符（+ CTC blank）

二、环境准备（三条命令）

需要 Python 3.9 或更高。命令行执行：

pip install onnxruntime numpy pillow

就这三个依赖。把 crnn_math.onnx 和下面的脚本放在同一个文件夹。

三、直接能跑的完整代码

保存为 demo.py，和模型放一起，把最后改成你的图片文件名，运行 python demo.py：

import io
import numpy as np
import onnxruntime as ort
from PIL import Image

CHARS = "0123456789加减乘除"
IDX_TO_CHAR = {i + 1: c for i, c in enumerate(CHARS)}   # 0 是 CTC blank，不是字符

# ---------- 1. 预处理：参数必须和训练完全一致，一个都不能改 ----------
def preprocess(png_bytes):
    img = Image.open(io.BytesIO(png_bytes))
    img = img.convert("L").resize((200, 32), Image.Resampling.BILINEAR)
    arr = np.asarray(img, dtype=np.float32) / 255.0
    arr = (arr - 0.5) / 0.5          # 归一化到 [-1, 1]
    return arr[None, None, :, :]     # shape: (1, 1, 32, 200)

# ---------- 2. CTC 贪心解码 ----------
def decode(logits):
    x = logits.astype(np.float32)
    x = x - x.max(axis=-1, keepdims=True)
    e = np.exp(x)
    probs = e / e.sum(axis=-1, keepdims=True)
    if probs.ndim == 3:
        probs = probs[0]
    text, confs, prev = "", [], -1
    for t, k in enumerate(probs.argmax(axis=1)):
        k = int(k)
        if k != 0 and k != prev:                     # 0 = blank，去重去 blank
            ch = IDX_TO_CHAR.get(k, "")
            if ch:
                text += ch
                confs.append(float(probs[t, k]))
        prev = k
    return text, (min(confs) if confs else 0.0)      # 置信度 = 最弱字符的概率

# ---------- 3. 求值："7加9" → 16（除不尽/除零返回 None，建议换图） ----------
def solve(expr):
    import re
    m = re.fullmatch(r"(\d+)(加|\+|减|-|乘|\*|×|除|÷)(\d+)", expr)
    if not m:
        return None
    a, op, b = int(m.group(1)), m.group(2), int(m.group(3))
    if op in ("加", "+"):  return str(a + b)
    if op in ("减", "-"):  return str(a - b)          # 可为负数，直接提交
    if op in ("乘", "*"):  return str(a * b)
    return str(a // b) if b and a % b == 0 else None  # 除不尽 → None → 换图

# ---------- 4. 用起来 ----------
sess = ort.InferenceSession("crnn_math.onnx",
                            providers=["CPUExecutionProvider"])
IN = sess.get_inputs()[0].name

png = open("captcha.png", "rb").read()               # ← 换成你的验证码图片
text, conf = decode(sess.run(None, {IN: preprocess(png)})[0])
print(f"算式原文: {text!r}  置信度: {conf:.3f}")

answer = solve(text)
print(f"答案: {answer if answer is not None else '(除不尽/格式异常，换一张图)'}")

输出示例：

算式原文: '7加9'  置信度: 0.987
答案: 16

五、置信度怎么用

解码返回的置信度 = 整条算式里最没把握那个字符的概率（最弱环节）。实战建议：

  • ≥ 0.90：直接用
  • < 0.90：别赌，换一张验证码重新识别（错误识别的代价是提交错误答案）
  • 本项目实测：8 个错误样本里 5 个置信度 ≥ 0.888、4 个接近 1.0 —— 错误是“看不见字边界”而非“犹豫”，阈值没法救回来，只能靠换图
  • 求值阶段除不尽（如 2除7）或除零 → None → 同样换图

六、训练数据分布（了解即可，影响预期）

运算符占比注意
加 / 乘 / 除约 24%–26%两个操作数都只有 1 位数（7加9）
减约 26%64% 的减法 B 是两位数（55减23），且 6.5% 结果为负（1减8）

训练/测试集共约 3300 张标注图，全部来自同一门户真实验证码。换成别的门户的验证码图，效果无法保证（字体、干扰线风格不同）。
